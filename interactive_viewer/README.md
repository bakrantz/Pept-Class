## Interactive single-channel recording viewer

# Load a CSV or ATF file type 

# Mark a range of data to make a snippet with Shift-Click
	-First be sure to not be in the magnifying glass tool (click that off)
	-Then Shift-Click and move green data selectors over range of data to make snippet
	-Hit 's' to save to enumerated snippet files (note the find will autosave in the format you loaded, and the save PNG window with also open, but you can just hit cancel on that unless you want an image.)
	
# Find a mean current value over a range of data
	-First be sure to not be in the magnifying glass tool (click that off)
	-Then Shift-Click and move green data selectors over range of data to find mean value
	-Hit 'm' to save to enumerated snippet files
